# A Curious Trajectory · rainedrops

An experimental 25-second career story told through a pencil-drawn UFO flying across an interactive galaxy. Created as a class project for ELISAVA.

**Live site:** https://byraine.github.io/rainedrops/

### How to use
Move your mouse or finger across the full screen to steer the alien spaceship, or use the arrow keys. Fly into either black hole, or click/tap it, to spiral through a wormhole and appear in another part of space. The seven symbols represent Cox Automotive, bilingual education, writing, film, photography, creative direction, and ELISAVA. Choose **Replay Story** to restart the sequence. You can keep exploring after the story ends.

### How it works
The website is built entirely in **`index.html`** (embedded CSS, JavaScript, SVG, Canvas starfield). No external libraries or build tools are required; GitHub Pages serves the root file. The older `styles.css` and `script.js` remain as historical files but are not referenced by the current page. See [ANIMATION_BRIEF.md](ANIMATION_BRIEF.md) for the creative brief.

### Publishing
GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Reload the live website after the deployment finishes.
